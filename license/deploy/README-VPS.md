# Лицензионный сервер на VPS (200–300 ₽/мес) — пошагово

Зачем: сервер лицензий должен работать **всегда**, пока покупатели вводят
ключи и играют. Домашний ПК для этого не подходит — нужен дешёвый VPS.

Серверу хватает минимального тарифа (1 vCPU / 1 ГБ RAM / 10 ГБ диска):
FastAPI + SQLite потребляют ~100 МБ памяти.

## Шаг 1. Купить VPS

Подходящие варианты в бюджете 200–300 ₽/мес (минимальный тариф любого из них):

| Провайдер | Цена от | Примечание |
| --- | --- | --- |
| [JustHost.ru](https://justhost.ru) | ~193 ₽/мес | KVM, много локаций, оплата картами РФ |
| [Aeza](https://aeza.net) | ~199 ₽/мес (промо) | DDoS-защита в базе, почасовая тарификация |
| [Timeweb Cloud](https://timeweb.cloud) | ~300–480 ₽/мес | попроще для новичка, почасовая оплата |

При заказе:
- операционная система: **Ubuntu 22.04 или 24.04** (или Debian 12);
- локация: любая российская (Москва/СПб) — пинг ниже;
- оплата на месяц, дальше продлишь.

После оплаты панель покажет: **IP-адрес**, логин **root** и **пароль**.
Сохрани их.

## Шаг 2. Первый вход по SSH

На твоём ПК (Windows 10/11 — SSH уже встроен) открой PowerShell:

```
ssh root@ТВОЙ_IP
```

Введи пароль (при вводе символы не показываются — это нормально).
Оказавшись на сервере, обнови систему:

```
apt update && apt upgrade -y
```

## Шаг 3. Загрузить файлы лицензии на сервер

На своём ПК (в папке проекта) выполни в PowerShell:

```
ssh root@ТВОЙ_IP "mkdir -p /opt/1832"
scp -r license root@ТВОЙ_IP:/opt/1832/
```

Папка `license/` весит пару мегабайт. Исходники чита на сервер не нужны —
только эта папка. (Папку `license/keys/` можно не заливать — на сервере она
не нужна, но и вреда от неё нет.)

## Шаг 4. Установить сервер (одна команда)

На сервере по SSH:

```
cd /opt/1832/license/deploy
bash install.sh
```

Скрипт сам: поставит python, создаст окружение, установит systemd-сервис с
**автозапуском и автоперезапуском при сбое**, запустит сервер и покажет
внешний адрес.

После установки **обязательно** смени админ-токен:

```
nano /opt/1832/license/config.json
```

(в `admin_token` впиши своё секретное слово, Ctrl+O — сохранить, Ctrl+X —
выйти), затем:

```
systemctl restart 1832-license
```

## Шаг 5. Открыть порт 8000

1. В панели VPS (веб-интерфейр провайдера) проверь, что фаервол не блокирует
   порт 8000 (у большинства он открыт по умолчанию).
2. Если на сервере включён ufw:
   ```
   ufw allow 8000/tcp
   ```

## Шаг 6. Проверить

С твоего ПК (PowerShell в папке `license\deploy`):

```
.\check_server.ps1 http://ТВОЙ_IP:8000
```

Должно быть: `OK: сервер отвечает, статус = ok`.

Открой в браузере `http://ТВОЙ_IP:8000/api/health` — увидишь
`{"status":"ok","keys":N}`.

## Шаг 7. Подключить DLL к серверу

Два способа (можно оба):

1. **При сборке**: в `18_32_cheat/Core/LicenseNet.cpp` поменяй
   `kDefaultServerUrl` на `http://ТВОЙ_IP:8000` и пересобери DLL — адрес
   будет зашит.
2. **Без пересборки**: у покупателя рядом с `license.dat` лежит файл
   `%APPDATA%\18_32_cheat\server.txt` с адресом `http://ТВОЙ_IP:8000`
   (он перекрывает зашитый).

## Повседневные команды (на сервере, по SSH)

| Что | Команда |
| --- | --- |
| Статус сервиса | `systemctl status 1832-license` |
| Логи (онлайн) | `journalctl -u 1832-license -f` |
| Перезапуск | `systemctl restart 1832-license` |
| Обновить код | перезалей папку `license` (кроме `config.json` и `licenses.db`), затем `systemctl restart 1832-license` |
| Бэкап базы ключей | `scp root@ТВОЙ_IP:/opt/1832/license/licenses.db .` (с твоего ПК) |

База ключей — один файл `/opt/1832/license/licenses.db`. Раз в месяц
скачивай его себе — это вся информация о проданных ключах.

## Что будет, если VPS упадёт

- systemd перезапустит сервис автоматически (Restart=always);
- при переустановке VPS: повтори шаги 3–5 и верни `config.json` + `licenses.db`
  из бэкапа — все привязки и сроки сохранятся.

## Ограничения по честному труду

- Секрет подписи ключей лежит в `license/keylib.py` на сервере — доступ к
  VPS есть только у тебя (не передавай пароль root никому).
- `admin_token` из `config.json` нужен для команд отвязки/отзыва ключей —
  смени его при установке.

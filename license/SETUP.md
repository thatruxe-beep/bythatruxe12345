# Пошаговая настройка: Telegram-бот + лоадер + ключи

Цель: создал ключ в Telegram → сразу вставил его в лоадер → лоадер запускает игру.
Всё уже написано в коде, нужно только настроить и собрать. Порядок: один раз
настроить (части 1–2), дальше пользоваться циклом из части 3.

---

## Часть 1. Подготовка на твоём ПК (делается один раз)

### 1.1. Установи Python

1. Скачай Python 3.10+ с https://www.python.org/downloads/
2. При установке ОБЯЗАТЕЛЬНО поставь галочку **Add python.exe to PATH**.
3. Проверь: открой командную строку (Win+R → `cmd`) и набери `python --version` —
   должна показаться версия.

### 1.2. Установи зависимости

Открой командную строку в папке проекта и выполни:

```
pip install -r license\requirements.txt
```

### 1.3. Создай бота в Telegram

1. В Telegram найди **@BotFather** (официальный, с синей галочкой) → Start.
2. Отправь `/newbot`.
3. Имя — любое, например `18:32 ключи`.
4. Юзернейм — латиницей, должен заканчиваться на `bot`, например `cheat1832_keys_bot`.
5. BotFather пришлёт **токен** вида `7712345678:AAE9kxY...` — скопируй его целиком.
   Никому не показывай токен.

### 1.4. Узнай свой Telegram ID

Открой **@userinfobot** → Start → он ответит `Id: 123456789`. Запиши это число.

### 1.5. Создай config.json

В папке `license\` скопируй `config.example.json` и переименуй копию в `config.json`.
Открой блокнотом и заполни:

```json
{
  "server": { "host": "127.0.0.1", "port": 8000 },
  "database": "licenses.db",
  "admin_token": "придумай_длинное_секретное_слово",
  "binding": { "hwid": false },
  "telegram": {
    "bot_token": "ТОКЕН_ИЗ_ШАГА_1.3",
    "admin_ids": [ТВОЙ_ID_ИЗ_ШАГА_1.4]
  }
}
```

`binding.hwid`: поставь `true`, если ключ должен автоматически привязываться
к первому компьютеру, где его активировали (перенести на другой ПК тогда можно
только через `/reset`). Для начала рекомендую `false`.

## Часть 2. Сборка лоадера (делается один раз)

Нужен Visual Studio 2022 (Community подойдёт).

### 2.1. Установи Visual Studio

1. Скачай Visual Studio 2022 Community: https://visualstudio.microsoft.com/ru/
2. При установке отметь нагрузку **«Разработка классических приложений на C++»**
   (Desktop development with C++).
3. Дождись установки (несколько ГБ).

### 2.2. Собери лоадер

1. В меню «Пуск» найди и открой **Developer PowerShell for VS 2022**
   (именно Developer PowerShell — там доступен MSBuild).
2. Перейди в папку проекта:
   ```
   cd C:\путь\к\папке\с\проектом
   ```
3. Собери:
   ```
   .\tools\build-loader.ps1
   ```
4. В конце должно быть зелёное `Built successfully: ...\build\18_32_loader.exe`.

### 2.3. Подготовь папку лоадера

1. Создай папку, например `C:\1832\`.
2. Скопируй туда `build\18_32_loader.exe`.
3. Рядом создай файл `loader.ini` (обычный текстовый файл, блокнот) с содержимым:
   ```ini
   [loader]
   server=http://127.0.0.1:8000
   game=C:\Games\GTA San Andreas\gta_sa.exe
   ```
   В `game` укажи свой реальный путь к `gta_sa.exe`.
4. Запусти `18_32_loader.exe` — должно открыться окно «18:32 CHEAT / LICENSE LOADER»
   с полем для ключа.

## Часть 3. Рабочий цикл: новый ключ → лоадер

### 3.1. Запусти сервер и бота (два окна, держи открытыми)

1. Двойной клик `license\start-server.bat` — работает, если в конце надпись про
   `Uvicorn running on http://127.0.0.1:8000`.
2. Двойной клик `license\start-bot.bat` — работает, если написано
   `[bot] запущен, жду сообщений…`.

### 3.2. Создай ключ в Telegram

1. Открой своего бота (юзернейм из шага 1.3) → Start.
2. Отправь команду:
   ```
   /gen 30
   ```
   — получишь ключ вида `XXXX-XXXX-XXXX-XXXX` на 30 дней.
   Другие сроки: `/gen 180`, `/gen 365`, или любое число дней: `/gen 45`.
   Несколько ключей сразу: `/gen 30 5`. С заметкой: `/gen 365 1 ник_покупателя`.

### 3.3. Вставь ключ в лоадер

1. Открой `18_32_loader.exe`.
2. Вставь ключ в поле (Ctrl+V) — дефисы можно не печатать, регистр не важен.
3. Нажми **АКТИВИРОВАТЬ**.
4. Лоадер покажет: «ПОДПИСКА АКТИВНА», сколько дней осталось и дату окончания.
   С этого момента срок пошёл (до активации ключ «спит» и не сгорает).
5. Кнопка **ЗАПУСТИТЬ GTA: SA** станет активной — нажми, игра запустится.

Ключ сохраняется в `loader.ini` автоматически: при следующем запуске лоадер
проверит его сам, заново вставлять не нужно.

### 3.4. Что видит покупатель, когда срок вышел

Лоадер покажет «ПОДПИСКА ИСТЕКЛА» и кнопку запуска заблокирует. Для продления
выдаёшь новый ключ — покупатель вставляет его и активирует заново.

### Команды бота (шпаргалка)

| Команда | Что делает |
| --- | --- |
| `/gen <дней> [сколько] [заметка]` | создать ключи |
| `/keys` | последние 20 ключей |
| `/info <ключ>` | статус, срок, активация, привязка |
| `/revoke <ключ>` | отозвать ключ (мгновенно блокирует) |
| `/restore <ключ>` | вернуть отозванный |
| `/reset <ключ>` | отвязать от ПК (если hwid включён) |

## Часть 4. Если лоадер запускается на ДРУГОМ компьютере

По умолчанию всё локально (`127.0.0.1`). Если лоадер у покупателя, а сервер у тебя:

1. В `license\config.json` поменяй хост:
   ```json
   "server": { "host": "0.0.0.0", "port": 8000 }
   ```
2. Разреши порт в брандмауэре Windows (одна команда в консоли от администратора):
   ```
   netsh advfirewall firewall add rule name="1832 license" dir=in action=allow protocol=TCP localport=8000
   ```
3. Узнай свой IP (`ipconfig`) и в `loader.ini` у покупателя укажи:
   ```ini
   server=http://ТВОЙ_IP:8000
   ```
4. Твой компьютер должен быть включён, сервер — запущен, пока покупатель
   проверяет ключ.

Для проверки локальной работы ничего из этого не нужно.

## Частые проблемы

| Симптом | Причина и решение |
| --- | --- |
| Лоадер: «Сервер лицензий недоступен» | Не запущен `start-server.bat`. Запусти и нажми «ПРОВЕРИТЬ». |
| «Такого ключа нет» | Опечатка в ключе или ключ создан на другой базе (удалён `licenses.db`). |
| Бот молчит | Окно `start-bot.bat` закрыто, или в `config.json` неверный токен. Проверь токен у @BotFather (`/mybots`). |
| Бот: «Нет доступа» | В `admin_ids` указан не твой ID. Проверь у @userinfobot. |
| `msbuild не найден` при сборке | Запускай сборку из **Developer PowerShell for VS 2022**, не из обычной консоли. |
| «Не удалось запустить игру» | В `loader.ini` неверный путь в `game=`. Укажи полный путь к `gta_sa.exe`. |

Готово: цикл «создал ключ → вставил в лоадер → играем» настроен.
